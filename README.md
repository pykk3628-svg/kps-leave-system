# ระบบใบลานักเรียน (Google Apps Script)

นักเรียนพิมพ์ชื่อหรือเลขที่ ระบบเติมชื่อ ห้อง เลขที่ และลาครั้งที่ให้เอง นักเรียนกรอกช่วงวันที่ สาเหตุ และแนบรูปหลักฐาน (บังคับ) ครูอนุมัติในหน้าเว็บ พิมพ์เป็น PDF ได้ และมีข้อความแจ้งเข้า LINE ทุกครั้งที่มีใบลาใหม่

ข้อมูลทั้งหมดอยู่ใน Google บัญชีของครูที่ติดตั้ง (Google Sheet + Google Drive)

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `Code.gs` | ฝั่งเซิร์ฟเวอร์: ค้นรายชื่อ, บันทึกใบลา, เก็บรูปใน Drive, สร้าง PDF, ส่ง LINE, รับ webhook |
| `Index.html` | หน้าเว็บของนักเรียนและครู |
| `appsscript.json` | ค่าตั้งโปรเจกต์ (เขตเวลา สิทธิ์ที่ต้องใช้ การเผยแพร่) |

## ติดตั้งครั้งแรก

1. สร้าง Google Sheet ใหม่ แล้วเปิด **ส่วนขยาย > Apps Script**
2. วางโค้ดจาก `Code.gs` ทับไฟล์เดิม, สร้างไฟล์ HTML ชื่อ `Index` วางโค้ดจาก `Index.html`
3. ใน **Project Settings** ติ๊ก *Show "appsscript.json" manifest file* แล้ววางเนื้อหาจาก `appsscript.json` ทับ
4. กลับไปที่ Sheet รีเฟรช เมนู **ระบบใบลา > 1. ตั้งค่าเริ่มต้น** (กดอนุญาตสิทธิ์ทุกอย่างที่ขึ้นมา)
5. **ใส่รายชื่อนักเรียนในชีต Students** (ดูหัวข้อถัดไป)
6. เมนู **2. ตั้งรหัสครู**
7. **Deploy > New deployment > Web app** ตั้ง Execute as เป็น **Me** และ Who has access เป็น **Anyone** แล้วแจกลิงก์ `/exec` ให้นักเรียนและครู

## รายชื่อนักเรียน (ชีต Students)

ใส่แถวละหนึ่งคน 3 คอลัมน์ ตามหัวตาราง `name`, `grade`, `no`

| name | grade | no |
|---|---|---|
| สมชาย ใจดี | ม.2/3 | 14 |
| สมหญิง รักเรียน | ม.2/3 | 15 |

- นักเรียนพิมพ์ **ชื่อ** (เต็มหรือบางส่วน) หรือ **เลขที่** แล้วระบบเติมชื่อ ห้อง เลขที่ให้อัตโนมัติ และล็อกไม่ให้แก้
- ถ้าชื่อบางส่วนหรือเลขที่ตรงกับหลายคน (เช่น เลขที่ 14 มีหลายห้อง) ระบบให้เลือกห้องก่อน
- **ลาครั้งที่** ระบบนับให้จากใบลาที่ผ่านมาของนักเรียนคนนั้น (ไม่นับใบที่ไม่อนุมัติ) และ **จำนวนวัน** นับให้จากช่วงวันที่ โดยไม่รวมเสาร์–อาทิตย์ ทั้งสองค่าคำนวณฝั่งเซิร์ฟเวอร์ แก้จากหน้าเว็บไม่ได้
- ชื่อที่ไม่อยู่ในรายชื่อจะเข้าใช้งานไม่ได้
- **ถ้าชีต Students ว่าง** ระบบเปิดให้นักเรียนกรอกชื่อ ห้อง เลขที่ เองทุกครั้ง (ไม่เติมอัตโนมัติ)

## ถ้าเคยติดตั้งเวอร์ชันก่อนหน้าแล้ว

1. วางโค้ดใหม่ทั้ง 3 ไฟล์ทับของเดิม (`appsscript.json` ต้องวางด้วย เพราะเพิ่มสิทธิ์สร้างเอกสารสำหรับ PDF)
2. กลับไปที่ Sheet รีเฟรช แล้วกดเมนู **ระบบใบลา > 1. ตั้งค่าเริ่มต้น** อีกครั้ง
   - ระบบจะขอสิทธิ์เพิ่ม (Google Docs) ให้กดอนุญาต
   - ชีต **Leaves** เดิมที่คอลัมน์ไม่ตรงกับเวอร์ชันนี้ จะถูกเปลี่ยนชื่อเป็น `Leaves_เก่า_วันที่เวลา` เก็บไว้ ข้อมูลไม่หาย แล้วสร้างชีต Leaves ใหม่ให้
   - ชีต **Students** เดิมที่มีคอลัมน์ PIN จะถูกเปลี่ยนชื่อเป็น `Students_เก่า_วันที่เวลา` แล้วสร้างชีต Students ใหม่ ให้คัดลอกชื่อ ห้อง เลขที่ ไปวางในชีตใหม่
3. **Deploy > Manage deployments > ไอคอนดินสอ > Version: New version > Deploy** ลิงก์เดิมจะใช้โค้ดใหม่

## การใช้งาน

**นักเรียน**
- พิมพ์ชื่อหรือเลขที่ที่หน้าแรก แล้วกรอกใบลา: ช่วงวันที่ ประเภทการลา สาเหตุ
- **ต้องแนบรูปภาพประกอบ** (ถ่ายรูปหรือเลือกรูป เช่น ลายเซ็นผู้ปกครอง ใบรับรองแพทย์) ไม่แนบจะส่งไม่ได้ ทั้งในหน้าเว็บและฝั่งเซิร์ฟเวอร์
- ปุ่ม "ล้างฟอร์ม" ล้างสาเหตุ วันที่ และรูป
- ดูสถานะใบลาของตัวเอง และถอนใบลาที่ยังไม่ถูกตัดสินได้

**ครู**
- กด "สำหรับครู" ใส่รหัสครู ดูใบลา กดดูรูปหลักฐาน อนุมัติหรือไม่อนุมัติพร้อมหมายเหตุ
- **พิมพ์ PDF** มี 3 แบบ
  - *พิมพ์ PDF รายการนี้* รายงานใบลาตามแท็บและคำค้นที่เลือกอยู่ (รออนุมัติ / ลาวันนี้ / ทั้งหมด) เป็นตารางแนวนอน
  - *พิมพ์ PDF สรุปรายคน* ที่แท็บ "สรุปรายคน" รวมวันลาที่อนุมัติแล้ว แยกป่วย/กิจ/อื่น ๆ
  - *พิมพ์ใบลานี้เป็น PDF* ที่แต่ละใบ เป็นแบบฟอร์มใบลาแบบเอกสาร (ลาครั้งที่ เรียน ข้าพเจ้า ประสงค์ขออนุญาต ลงชื่อ) พร้อมผลการพิจารณา ช่องลงชื่อครู และรูปหลักฐาน
- กดแล้วรอสักครู่ จะมีกรอบสีเขียวพร้อมปุ่ม **ดาวน์โหลด** และ **เปิดดู** (ถ้าเบราว์เซอร์ไม่ดาวน์โหลดอัตโนมัติ ให้กดปุ่มเอง)
- ระบบเก็บสำเนา PDF ไว้ในโฟลเดอร์ `ใบลา-รูปภาพ/PDF` ใน Drive ของเจ้าของระบบด้วย

## ตั้ง LINE Official Account (แจ้งเตือนครู)

ใช้ LINE Messaging API ส่งข้อความหาครูแต่ละคน (LINE Notify ปิดบริการแล้ว)

1. สร้าง LINE Official Account ที่ manager.line.biz แล้วเปิด **Settings > Messaging API > Enable**
2. ที่ developers.line.biz เข้า Channel ของบอท แท็บ **Messaging API** ล่างสุด กด **Issue** ที่ *Channel access token (long-lived)* แล้วคัดลอก (ไม่ใช่ Channel secret)
3. ใน Sheet เมนู **3. ตั้ง LINE Channel Access Token** วาง token
4. ใส่ลิงก์ `/exec` ที่ช่อง **Webhook URL** ของ Channel เปิด **Use webhook** (ปุ่ม Verify ขึ้นไม่ผ่านเป็นเรื่องปกติของ Apps Script)
5. ครูแต่ละคนเพิ่มบอทเป็นเพื่อน แล้วพิมพ์ข้อความหาบอท 1 ครั้ง ชื่อจะขึ้นในชีต **Notify**
6. ตั้งคอลัมน์ `active` เป็น `TRUE` เฉพาะครูที่จะรับแจ้งเตือน แล้วกดเมนู **4. ทดสอบแจ้งเตือน LINE**

ข้อควรรู้: แต่ละแพ็กเกจของ LINE OA มีโควตาข้อความต่อเดือน นับตามจำนวนคนที่ได้รับ ตรวจที่ OA Manager

## ความปลอดภัยและข้อจำกัด (อ่านก่อนใช้จริง)

- **นักเรียนเข้าด้วยชื่อหรือเลขที่เท่านั้น ไม่มี PIN** ใครรู้ลิงก์และรู้ชื่อเพื่อน ก็ส่งใบลาในนามเพื่อนได้ ด่านกันคือครูต้องอนุมัติ และใบลาต้องมีรูปหลักฐาน ถ้าพบการปลอมใบลา ให้ไม่อนุมัติ หรือกลับไปใช้ PIN
- ชื่อ ห้อง เลขที่ ที่ใบลาใช้ มาจากชีต Students เสมอ ต่อให้แก้ค่าจากหน้าเว็บก็ไม่มีผล
- หน้านักเรียนแสดงเฉพาะสถานะของใบลา (ครั้งที่ ประเภท วันที่ สถานะ หมายเหตุจากครู) ไม่แสดงสาเหตุหรือรูป แต่ใครเข้าด้วยชื่อหรือเลขที่ของคนอื่นจะเห็นสถานะนี้ได้
- นักเรียนมีใบลารออนุมัติได้พร้อมกันไม่เกิน 5 ใบต่อคน กันการส่งซ้ำ ๆ
- รหัสครูผิดเกิน 5 ครั้งจะถูกล็อก 10 นาที รหัสและ LINE token เก็บใน Script Properties ไม่อยู่ในชีต
- ใบลามีข้อมูลสุขภาพและรูปภาพ ถือเป็นข้อมูลส่วนบุคคล ควรแชร์ชีตให้เฉพาะครูที่จำเป็น และแจ้งผู้ปกครองตามนโยบายของโรงเรียน
- ใบลาที่ครูตัดสินแล้ว นักเรียนถอนหรือแก้เองไม่ได้
